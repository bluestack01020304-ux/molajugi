# 몰아주기 디자인: 당근마켓 틀 + 인디고 포인트

작성일: 2026-11-07. 상태: 승인됨 (대화에서 목업 3종 확인).

## 의도

지금 UI는 동작 확인용(주황 포인트, 흰 카드, 이모지 아이콘)이다. 사용자가 원하는 인상은 "당근마켓처럼 깔끔하고 믿음직". 당근마켓의 레이아웃 문법(흰 바탕, 진한 회색 글씨, 연한 회색 보조 글씨, 얇은 구분선, 왼쪽 네모 썸네일, 테두리 칩, 떠 있는 올리기 버튼)을 가져오되, 색은 당근 주황을 피해 **인디고 블루 하나**만 포인트로 쓴다.

## 확정된 선택 (사용자)

- 홈 목록 C안: 가격 줄을 `50% 2,250원 ~~4,500원~~` 한 줄로. 확률 숫자만 인디고, 액면가는 취소선 연회색.
- 포인트 색: 인디고 블루 `#3B5BDB`.
- 나머지 화면(상세, 긁기, 당첨, 내 판매)은 보여준 목업대로.

## 작성자가 정한 것

- 헤더의 포인트 잔액은 뺀다. 잔액은 상세 화면 하단과 내 정보에서만 보인다.
- 홈 헤더: 왼쪽에 "몰아주기" 굵은 제목, 오른쪽에 알림 종 아이콘(미읽음 있으면 작은 점). 종을 누르면 내 정보 탭. 검색 아이콘은 기능이 없으므로 넣지 않는다.
- 당첨 화면은 색을 더 얹지 않는다. 인디고 큰 글씨 "당첨!" + 🎉 하나.
- 긁는 코팅은 차가운 회색 빗금(`#C9CCD3` / `#BFC3CB`).
- 아이콘은 이모지 대신 `@expo/vector-icons`의 Ionicons outline 계열(Expo Go에 포함).
- 상태 뱃지 톤은 네 가지로 줄인다: 인디고(진행), 노랑(대기), 초록(완료), 회색(종료). 경고/신고만 빨강.
- 글꼴은 시스템 기본(iOS Apple SD Gothic, Android Noto Sans KR). 별도 폰트 설치 없음.

## 토큰 (한 파일 `app/src/lib/theme.ts`에만 존재)

색:
- `primary #3B5BDB`, `primarySoft #EDF2FF`
- `ink #212124`(본문·제목), `sub #868B94`(보조), `faint #ADB1BA`(취소선·플레이스홀더)
- `line #F2F3F6`(구분선), `bg #FFFFFF`, `bg2 #F7F8FA`(썸네일·히어로·입력 배경)
- `danger #E03131`, `dangerSoft #FFF0F0`
- 뱃지: `live` = primarySoft/primary, `hold` = `#FFF4D6`/`#9A6B00`, `ok` = `#E6F6EA`/`#1E7B3A`, `warn` = dangerSoft/danger, `muted` = `#F1F3F5`/sub
- 긁기 코팅 `coatA #C9CCD3`, `coatB #BFC3CB`

글자(크기/굵기): `screenTitle 20/800`, `headerTitle 18/700`, `rowTitle 15/500`, `price 15/700`, `priceBig 20/800`, `meta 12/400 sub`, `body 14/400`, `button 15/700`, `label 13/600 sub`.

모서리: `sm 8`(썸네일·입력), `md 12`(버튼·히어로·카드), `pill 20`(칩), `fab 24`.

간격: 화면 좌우 16, 행 상하 14, 행 내부 gap 12, 썸네일 72(목록)/52(내 판매·내 기프티콘).

## 화면 규칙

- **공통 헤더**: 흰 배경, 그림자 없음, 제목 왼쪽 정렬 18/700, 뒤로가기 검정.
- **홈 목록**: 헤더(제목+종) → 테두리 칩 행(선택 = 검정 배경 흰 글씨) → 행 목록. 행 = 72 네모 썸네일(bg2, 모서리 8, 카테고리 아이콘) · 제목 `브랜드 상품명` 15/500 한 줄 말줄임 · 메타 `카테고리 · N일 남음` 12 sub · 가격 줄 `[확률%] [가격]원 [~~액면가~~]`. 오른쪽 아래 FAB `+ 올리기`(인디고, 그림자). 목록 하단 여백 96(FAB 가림 방지).
- **상세**: 히어로 160 bg2 모서리 12, 상품명 20/800, 보조 `카테고리 · 유효기간 YYYY.MM.DD (N일 남음)`, 표 3줄(액면가 / 당첨 확률(인디고 800) / 지금까지 꽝) 구분선 line. 하단 바: 왼쪽 `가격 20/800 + 취소선 액면가`, 오른쪽 `내 포인트 N` 12 sub, 그 아래 인디고 버튼 `N원으로 뽑기`. 포인트 부족 시 버튼 비활성 + 빨강 안내문 유지.
- **긁기**: 안내문 "손가락으로 긁어 보세요" sub, 코팅 회색 빗금, 드러나는 글씨 당첨=인디고 44/900, 꽝=sub. 긁기 전 하단 버튼은 흐리게.
- **당첨/꽝 결과**: 당첨 = 🎉 + "당첨!" 인디고 34/900 + 상품명 sub, 버튼 `바코드 보기`(인디고). 꽝 = "꽝" sub 28/800 + "아쉽네요" + `같은 기프티콘 다시 뽑기`(primarySoft 바탕, 인디고 글씨) + `목록으로`(테두리).
- **내 기프티콘 / 내 판매**: 행 = 52 썸네일 · 제목 · 메타 · 오른쪽 상태 뱃지. 내 판매엔 FAB `+ 올리기`(기존 상단 버튼 제거).
- **당첨 바코드**: 제목 `🎉 브랜드`, 이미지 박스 bg2 모서리 12, 번호 monospace 22, 안내문 body, 버튼 `정상 사용했어요`(인디고) / `이미 쓰인 바코드예요`(빨강 테두리).
- **올리기 폼**: 라벨 13/600 sub, 입력 bg2 모서리 8 테두리 없음, 확률 보기 선택 = 인디고 테두리 + primarySoft, 설명 한 줄 body, 푸터 버튼 인디고.
- **내 정보**: 잔액 36/800, 버튼 행(충전 인디고 / 출금 비활성 회색), 로그아웃은 sub 텍스트, 알림함 행 구분선 line.
- **로그인**: 제목 "몰아주기" 32/800 ink, 입력 bg2, 버튼 인디고, 전환 링크 인디고.
- **탭바**: Ionicons `home`, `ticket`, `pricetag`, `person` outline/filled 전환, 선택 = ink, 비선택 = sub, 라벨 10. 첫 탭 라벨은 목업대로 "홈"(기존 "뽑기"에서 변경, 사용자가 목업으로 확인).
- **스택 화면 헤더**(상세·결과·바코드·올리기): 탭 헤더와 같은 규칙(흰 배경, 그림자 없음, 왼쪽 정렬 18/700, 뒤로가기 ink).
